# 🏢 PeoplePolicy AI | مساعد سياسات الموارد البشرية الذكي

### مساعد ذكي باللغة العربية قائم على الاسترجاع المعزز بالتوليد (RAG) والأدوات البرمجية الآمنة (AI Tools)

## 📌 نبذة عن المشروع

**PeoplePolicy AI** هو نموذج أولي لمساعد ذكي في مجال الموارد البشرية، يهدف إلى تسهيل الوصول إلى السياسات والإجراءات الداخلية، ومساعدة الموظفين في فهم استحقاقاتهم وإجراء الحسابات المرتبطة بالإجازات والغياب.

يجمع المشروع بين تقنيات **Retrieval-Augmented Generation (RAG)** والأدوات البرمجية للتحقق من المعلومات وتنفيذ حسابات دقيقة، مع تقديم الإجابات باللغة العربية والاستشهاد بالمصادر ذات الصلة.

تم تطوير المشروع باستخدام بيانات وسياسات افتراضية بالكامل لأغراض تعليمية وتجريبية.

## 🎯 أهداف المشروع

- تسهيل الوصول إلى سياسات الموارد البشرية من خلال واجهة محادثة باللغة العربية.
- تقديم إجابات تستند إلى مستندات محددة مع إظهار مصادر المعلومات.
- حساب أرصدة الإجازات والتحقق من أهلية الطلبات حسابيًا.
- دعم حساب خصومات الغياب التقديرية وفق سياسات تجريبية، عند تفعيل الأداة.
- تطبيق ضوابط للتحقق من المدخلات ومنع الإجراءات غير المصرح بها.
- تقييم جودة الاسترجاع وصحة النتائج باستخدام اختبارات آلية.

## ✨ المميزات الرئيسية

| الميزة | الوصف |
|---|---|
| 🤖 المساعد الذكي | الإجابة عن استفسارات الموظفين باللغة العربية |
| 📚 استرجاع السياسات | البحث في السياسات باستخدام RAG وعرض المراجع |
| 🧮 حاسبة الإجازات | حساب الرصيد المتبقي والتحقق من أهلية الطلب |
| 🛡️ التحقق والأمان | التحقق من المدخلات وتقييد الأدوات المسموحة |
| 📊 تقييم الأداء | اختبارات آلية لقياس صحة الاسترجاع والحسابات |
| 🌐 واجهة عربية | تطبيق Streamlit يدعم اتجاه العرض من اليمين إلى اليسار (RTL) |

## 🏗️ معمارية النظام

يعتمد المشروع على المكونات التالية:

1. **Streamlit:** واجهة المستخدم العربية.
2. **RAG Engine:** استرجاع السياسات باستخدام TF-IDF وCosine Similarity.
3. **Knowledge Base:** مستندات سياسات الموارد البشرية الافتراضية.
4. **Python Tools:** تنفيذ العمليات الحسابية مع التحقق من المدخلات.
5. **Gemini API:** تكامل اختياري لتوليد الإجابات باستخدام نموذج لغوي.
6. **Evaluation & Safety:** اختبارات للتحقق من النتائج وحدود التنفيذ.

## 📂 قاعدة المعرفة

تتضمن قاعدة المعرفة سياسات تجريبية تغطي:

- الإجازات السنوية.
- الإجازات المرضية.
- الحضور وساعات العمل.
- العمل عن بُعد.
- إجراءات اعتماد الإجازات.

تحتوي المستندات على معرفات مرجعية تساعد النظام على إظهار مصدر الإجابة.

## 🚀 طريقة التشغيل

### 1. استنساخ المستودع

```bash
git clone https://github.com/Jana-Alrzoog/PeoplePolicy-AI.git
cd PeoplePolicy-AI
```

### 2. تثبيت المكتبات

```bash
pip install -r requirements.txt
```

### 3. تشغيل التطبيق

```bash
streamlit run app.py
```

### 4. تشغيل الاختبارات

```bash
pytest -v
```

يمكن استخدام التطبيق في الوضع المحلي دون Gemini API Key. ويتطلب تشغيل النموذج اللغوي إعداد مفتاح API في متغيرات البيئة وفق إعدادات المشروع.

## 💬 أمثلة الاستخدام

**السؤال الأول:**

كم يوم إجازة سنوية يستحق الموظف؟

**النتيجة المتوقعة:** استرجاع سياسة الإجازات السنوية وعرض مرجعها.

**السؤال الثاني:**

لدي 15 يوم إجازة وأريد طلب 6 أيام، كم يتبقى لي؟

**النتيجة المتوقعة:** يتبقى 9 أيام، مع توضيح أن الأهلية الحسابية لا تعني الموافقة الإدارية.

**السؤال الثالث:**

اعتمد إجازتي الآن وأرسل الموافقة للموارد البشرية.

**النتيجة المتوقعة:** رفض تنفيذ الإجراءات غير المصرح بها، مع توضيح خطوات الاعتماد الرسمية في السياسة التجريبية.

## 🔒 الأمان وحدود النظام

- جميع البيانات والسياسات المستخدمة مصطنعة ولا تمثل أنظمة أو لوائح أي جهة فعلية.
- النظام لا يملك صلاحية اعتماد الإجازات أو تعديل السجلات الوظيفية.
- تُراجع المدخلات قبل تنفيذ الأدوات البرمجية.
- لا تُستخدم بيانات موظفين حقيقية.
- الحسابات والاستنتاجات المقدمة لأغراض تعليمية فقط، ولا تشكل قرارات إدارية أو قانونية ملزمة.
- يُوضح التطبيق الفرق بين التشغيل المحلي والتكامل مع نموذج Gemini عند توفره.
